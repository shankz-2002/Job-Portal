# Job Portal

Job Portal is a recruitment platform that connects candidates and companies. Candidates can search and apply for jobs, while companies can create job postings, shortlist candidates, schedule interviews, and manage the recruitment process.

## Features

* Candidate and company registration and login
* Candidates can browse and apply for job postings
* Companies can create and manage job postings
* Companies can view and shortlist applicants
* Companies can schedule interviews with shortlisted candidates
* Candidates can view scheduled interviews and request a different interview date
* Companies can accept or reject interview date change requests
* Video call interviews
* Companies can accept or reject candidates after interviews
* Role-based access for candidates and companies

## Tech Stack

* Frontend: React.js,Material UI
* Backend:Node.js, Express.js, TypeScript
* Database: PostgreSQL, TypeORM
* Authentication:jwt


## Running Locally

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Environment Variables

Example environment files are provided for both the backend and frontend:

- Backend: `backend/.env.example`
- Frontend: `frontend/.env.example`

Copy the appropriate `.env.example` file to `.env` and add your own configuration values.
